# Соответствие нормативным актам

## ФЗ-149 от 27.07.2006 «Об информации, информационных технологиях и о защите информации»

- Работа в изолированном контуре (без доступа во внешние сети).
- Аудит всех действий пользователей (таблица `audit_logs`, хранение ≥ 6 мес.).
- Резервное копирование данных (ежедневно в 03:00).

## ФЗ-152 от 27.07.2006 «О персональных данных»

- Шифрование передаваемых данных (TLS/SSL внутри контура).
- Разграничение доступа по ролям (RBAC: admin / teacher / student).
- Минимизация обрабатываемых ПДн (только ФИО и логин).
- Хранение данных в локальной БД PostgreSQL без выгрузки во внешние сервисы.

## ГОСТ 34 (Комплекс стандартов на автоматизированные системы)

- Наличие сопроводительной документации (архитектура, установка, API, руководство).
- Открытый исходный код без обфускации.
- Возможность интеграции с другими системами через REST API.
