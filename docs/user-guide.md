# Руководство пользователя

## Роль: Администратор

1. Войти под учёткой `admin / admin123` (сменить пароль после первого входа).
2. Кабинет администратора — по адресу `/admin`.
3. Доступные действия:
   - Создать пользователя (роль: teacher / student / admin)
   - Заблокировать / разблокировать учётку
   - Просмотреть журнал аудита (последние 50 событий)
   - Создать резервную копию БД (кнопка «Создать резервную копию»)

## Роль: Преподаватель

1. Войти под учёткой, созданной администратором.
2. Кабинет преподавателя — `/teacher`.
3. Создание сценария:
   - Кнопка «Сгенерировать черновик сценария» — ИИ создаёт заготовку.
   - Проверить поля: адрес, тип, признаки, службы, эталонный текст.
   - Нажать «Опубликовать» — сценарий становится доступен студентам.
4. Назначение студенту:
   - Через API `POST /api/teacher/assign` (в UI — следующий шаг разработки).
5. Проведение занятия:
   - Студент запускает сессию сам.
   - Преподаватель видит сессии в списке и отчёты в таблице.

## Роль: Обучающийся

1. Войти под своей учёткой.
2. Кабинет обучающегося — `/student`.
3. Список назначенных сценариев отображается на главной.
4. Кнопка «Начать занятие» — создаёт сессию.
5. На экране появляется карточка АРМ-112:
   - Заполнить поля: фамилия, адрес, округ, район, улица, дом.
   - Выбрать тип происшествия.
   - Отметить признаки (открытое пламя, угроза людям и т.д.).
   - Выбрать службы (чек-боксы).
   - Ввести текст ответа.
6. Следить за таймером (по умолчанию 30 сек).
7. Нажать «Сохранить» — система рассчитывает оценку.
8. Отчёт доступен в разделе «Мои отчёты».

## Оценка

Итоговый балл складывается из:

- 30% — соблюдение тайминга
- 30% — совпадение текста ответа с эталоном
- 20% — правильность отмеченных признаков
- 15% — правильность выбранных служб
- 5% — грамматика

Балл ≥ 70 считается успешным.
